# Landing Page - Denise Cristina Cardoso Almeida

Landing page profissional para Denise Cristina Cardoso Almeida - Professora, Psicopedagoga e Neuropsicóloga especializada em educação inclusiva e primeira infância.

## 🧩 Sobre o Projeto

Este site foi desenvolvido com foco em inclusão e acessibilidade, utilizando a paleta de cores do autismo para representar diversidade, empatia e educação inclusiva.

## ✨ Características

- **Design Moderno e Responsivo**: Adaptável a todos os dispositivos
- **Paleta de Cores do Autismo**: Azul, vermelho, amarelo e ciano
- **Animações Interativas**: CSS moderno com efeitos suaves
- **Acessibilidade**: Estrutura semântica e navegação intuitiva
- **Seções Completas**:
  - Apresentação profissional
  - Experiência e formação
  - Áreas de atuação
  - Formulário de contato

## 🚀 Como Usar

1. Abra o arquivo `index.html` em qualquer navegador moderno
2. Navegue pelas seções usando o menu ou scroll
3. Preencha o formulário de contato para entrar em contato

## 🎨 Tecnologias

- HTML5 semântico
- CSS3 com animações e gradientes
- JavaScript vanilla para interatividade
- Design responsivo mobile-first

## 📱 Compatibilidade

- Chrome, Firefox, Safari, Edge (versões recentes)
- Dispositivos móveis e tablets
- Responsivo para todas as resoluções

## 💙 Paleta de Cores

- **Azul**: `#0099CC` - Confiança e profissionalismo
- **Vermelho**: `#FF3333` - Energia e paixão
- **Amarelo**: `#FFD700` - Otimismo e clareza
- **Ciano**: `#00BFFF` - Harmonia e inclusão
